# Release 1.1 backlog

Release 1.1 starts only after V1 tenant isolation, auth, migration/seed, browser, accessibility, performance, backup/restore, and pilot acceptance gates pass.

1. Persist every Web mutation through typed repositories and outbox events, including undo and realtime invalidation.
2. Production Google Drive OAuth/picker, encrypted refresh tokens, revocation, webhook verification, and permission-aware file metadata refresh.
3. GitHub App issue/PR linking and Figma OAuth metadata sync with provider health/status screens.
4. Google Calendar milestone projection and Slack update/decision notifications with granular subscription controls.
5. Formula and timeline/Gantt board views, automations, reusable saved filters, and large-board row/column virtualization.
6. Mobile companion expansion: My Work, Inbox, Quick Capture, item details, comments, approvals, push notifications, offline mutation queue, and conflict UX.
7. Desktop native expansion: global shortcut, tray capture, notifications, deep links, secure token vault, update/signing pipeline.
8. Full-text/trigram search, indexing telemetry, archived-content controls, and result snippets.
9. Import mapping UI, dry runs, error downloads, resumable background exports, and admin data-retention tools.
10. Passkeys/OAuth providers, invitation lifecycle UI, organization settings, SCIM/SSO discovery for later enterprise needs.
